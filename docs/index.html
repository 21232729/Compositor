  • 或在终端执行 or run this in Terminal

这一版有什么 · What's new

  • 一个文档多个美术板，各自独立创建、移动、缩放，可单独导出 PNGMultiple artboards per document, each movable, resizable and exportable on its own
  • 右键画板上的尺寸标签，直接输入精确宽高Right-click an artboard's size label to type an exact width and height
  • 工具按组收纳，右键组内按钮切换；折叠组带角标提示A grouped toolbar with right-click switching and a badge on collapsed groups
  • 新增钢笔工具绘制路径，与画笔同组A pen tool for paths, grouped with the brush
  • 字体拆成「字体族 + 样式」两个选择器，悬停即可预览Font family and style pickers, with hover preview
  • 选中文字范围可单独设颜色、字体、上标/下标Per-range color, font and superscript / subscript
  • 提交文字后自动切到移动工具，可立刻拖动Committing text hands the tool to Move, so you can drag it right away
  • 点击图层选图层、点击画板选画板；点击画板之外取消选择Precise auto-select: a layer picks the layer, a board's empty area picks the board, a click outside deselects
  • 图层面板缩略图按整个工作区取景，不再出现空白棋盘格Layer thumbnails frame the whole working area, so nothing shows as an empty checkerboard
